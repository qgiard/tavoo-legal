Politique de confidentialité — Tavoo

Dernière mise à jour : juin 2026

1. Collecte des données

L'application Tavoo collecte les données suivantes :

  • Adresse email (création de compte, connexion)
  • Recettes et listes de courses créées par l'utilisateur
  • Identifiants de compte Apple / Google (selon le mode de connexion choisi)
  • Tokens de notification push (optionnel)

2. Utilisation des données

Les données sont utilisées uniquement pour :

  • Permettre le fonctionnement de l'application (création de recettes, listes de courses, partage familial)
  • Synchroniser les données entre les appareils de l'utilisateur
  • Envoyer des notifications push si l'utilisateur y consent
  • Améliorer le service (analyse anonyme des usages)

3. Stockage et hébergement

Les données sont hébergées sur un serveur privé. Les mots de passe sont hachés (bcrypt). Les tokens Apple/Google sont validés mais jamais stockés.

4. Partage des données

Aucune donnée personnelle n'est vendue ou partagée avec des tiers. Les recettes et listes de courses sont partagées uniquement entre les membres d'un même foyer.

5. Durée de conservation

Les données sont conservées tant que le compte est actif. La suppression du compte entraîne la suppression définitive de toutes les données personnelles dans un délai de 30 jours.

6. Droits de l'utilisateur (RGPD)

Conformément au RGPD, l'utilisateur peut à tout moment :

  • Accéder à ses données
  • Demander la rectification ou la suppression de ses données
  • Demander la portabilité de ses données
  • Retirer son consentement aux notifications

Pour exercer ces droits : paramètres de l'application > Supprimer mon compte, ou nous contacter.
